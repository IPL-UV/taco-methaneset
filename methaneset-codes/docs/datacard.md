# Datacard

The datacard for each collection lives next to the data on Hugging Face:

- Dataset: https://huggingface.co/datasets/tacofoundation/methaneset
- Card: https://huggingface.co/datasets/tacofoundation/methaneset/blob/main/README.md

That card is the reference for samples, sizes, licenses and field-level metadata. This repository
only covers the code that produces them.
