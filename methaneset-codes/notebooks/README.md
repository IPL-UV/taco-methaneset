# Notebooks

End-to-end usage examples. They load the published datasets from Hugging Face, so they need no
local data and no credentials.

- `01_multispectral.ipynb` — load the finetune subset, read the plume masks, train a
  change-detection baseline.
- `02_hyperspectral.ipynb` — stream EMIT radiance, compare the matched-filter products and the
  two independent masks.
